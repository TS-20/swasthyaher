**Swasthya-Her 🌸**
**A Women’s Health and Wellness Website**
**Overview**
Swasthya-Her is a prototype web application designed to provide personalized women’s health recommendations. It incorporates predictive health tracking, a discussion forum, and clustering-based insights to enhance women’s well-being.

**Features**
✅ Predictive Women’s Health Tracker – Provides health insights based on user input.
✅ Community Discussion Forum – A platform for users to share experiences and seek advice.
✅ Personalized Health Recommendations – Clusters users based on health data using KNN for clustering.
✅ Scalable Architecture – Built with Flask API for easy integration with future ML models.
✅ User-Friendly Interface – Designed using HTML, CSS, and JavaScript.

**Tech Stack**
Backend: Python, Flask API
Frontend: HTML, CSS, JavaScript
Machine Learning: K-Nearest Neighbors (KNN) for clustering

**Future Scope**
🔹 Enhance ML models and use more accurate dataset.
🔹 Integrate real-world datasets for accurate health predictions.
🔹 Implement doctor consultation and subscription-based health plans.
